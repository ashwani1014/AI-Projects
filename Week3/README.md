# 👁️ Week 3 — Deep Learning, Computer Vision & CNNs

Welcome to **Week 3** of the 30-Day AI Engineering Journey!

---

## 📌 Weekly Focus
- **Deep Learning Foundations:** Artificial neurons, activation functions (ReLU, Sigmoid), multi-layer perceptrons, backpropagation.
- **PyTorch Mechanics:** Tensors, autograd, GPU acceleration (`cuda`), custom `Dataset` & `DataLoader`.
- **Training Pipeline:** Forward pass, loss calculation (`CrossEntropyLoss`), optimizer updates (`Adam`), model serialization (`.pth`).
- **Computer Vision & CNNs:** Convolutional layers (`Conv2d`), spatial pooling (`MaxPool2d`), feature flattening, and dense heads.
- **Data Augmentation:** Real-time affine transforms, flips, and normalization via `torchvision.transforms`.
